## 3. 构建

### 3.1 jbb.dylib

```sh
cd jb-bypass
sh scripts/build-jbb.sh                 # -> build/jbb.dylib (arm64+arm64e)
```

手工等价命令（关键点：**双架构**，签名必须最后）：

```sh
SDK=$(xcrun --sdk iphoneos --show-sdk-path)
clang -x objective-c -arch arm64 -arch arm64e -miphoneos-version-min=15.0 \
  -isysroot "$SDK" -fobjc-arc -O2 -fvisibility=hidden \
  -ffile-prefix-map="$PWD"=. -dynamiclib -framework Foundation \
  -o build/jbb.dylib src/jbb_v616.c
codesign -f -s - build/jbb.dylib
```

为什么必须双架构：App Store 的 App 是 **arm64** 进程（微信/支付宝都是），单 arm64e 的 dylib 注入不进去。

### 3.2 设置界面

```sh
sh scripts/build-prefs.sh
```

依赖：

- **roothide 的 Theos fork**（`https://github.com/roothide/theos`），官方 Theos 没有 `roothide` package scheme；
- `ldid` 在 PATH（本机用 `.buildtools/ldid` 这个 `codesign` 替身；注意它对 **dylib** 会丢 entitlements，对可执行文件正常）；
- `Preferences` 私有框架不在 SDK 里，所以 bundle 用 `-Wl,-undefined,dynamic_lookup`，运行时从 Settings 解析。

### 3.3 打包（一个 deb 含全部）

```sh
sh scripts/pack-deb.sh iphoneos-arm64e     # .20 用
sh scripts/pack-deb.sh iphoneos-arm64      # 仅当目标 dpkg 架构是 arm64
# -> dist/com.pandan.jbb_6.16_<arch>.deb
```

没有 `dpkg-deb` 时脚本回退到 `$THEOS/bin/dm.pl`（gzip 压缩，Sileo/dpkg 都认）。

## 5. 配置模型

### 5.1 全局

```xml
<key>globalEnabled</key><true/>       <!-- 总开关，默认开 -->
<key>globalExtraTokens</key><false/>  <!-- 额外 token，默认关 -->
```

### 5.2 按 App 覆盖（可选）

```xml
<key>profiles</key><dict>
  <key>com.tencent.mqq</key><dict>
    <key>enabled</key><true/>
    <key>file</key><true/>  <key>env</key><true/>
    <key>ptrace</key><true/> <key>ppid</key><true/>
    <key>dyld</key><false/> <key>name</key><false/>
    <key>sysctl</key><false/> <key>objc</key><false/> <key>csops</key><false/>
  </dict>
</dict>
```

没有条目的 App 用默认：所有 hook 开，只有 `env` 与 `extraTokens` 默认关。
配置在**进程启动时**读取，改完要杀掉目标 App 重开。

### 5.3 token 两级

- **core（26）**：本机真实痕迹 `/var/jb`、`.jbroot-`、`/basebin`、`systemhook`、`TweakInject`、ellekit/substrate、Sileo/Cydia/Zebra/Filza、RootHide、jbctl…
- **extra（19，默认关）**：其他越狱生态 apt/dpkg、cycript、bash、uicache、irisind/irisin/umbra/relaxin/cocoatop、libsandy、substitute、cydia…

匹配器自 6.15 起用「首字节锚点索引」，不再 N 次 `strstr`。

## 6. 验证方法（重要）

### 6.1 注入探针（绕过 TweakLoader 缓存）

```sh
JB=$(/usr/bin/jbroot)          # .20；.28 用 /var/jb
T="$JB/usr/lib/TweakInject"

jbctl trustcache add "$T/probe.dylib"
opainject <pid> "$T/probe.dylib"
```

两个坑：

1. **必须传 jbroot 前缀的真实路径**。传 `/var/jb/...` 会被 vroot 重定向，报 `Can't access passed dylib`；
2. 同一个 dylib 对同一进程 `opainject` 两次不会重跑 constructor（dlopen 返回已有 handle），换 build 必须重启目标进程。

`.28` 的 `opainject` 不接受上述路径、`trustcache add` 也不可用 → 目前只能走 TweakInject 过滤注入。

### 6.2 探针输出的两个可靠渠道

- **同步写文件**：constructor 里直接写，不依赖前台；
- **os_log**：`os_log_create("com.pandan.probe", ...)`，`log show --last 5m --predicate 'subsystem == "com.pandan.probe"'` 回读，App 进后台也不丢。

**不要用延迟 timer 写文件**：锁屏/后台时进程被挂起，block 不执行，会误判成"插件没生效"。

### 6.3 基准的坑

- 墙钟（`mach_absolute_time`）会把挂起时间算进去（曾测出 273 µs/op）；
- `CLOCK_PROCESS_CPUTIME_ID` 会把 App 其他线程算进去；
- 用 `CLOCK_THREAD_CPUTIME_ID`，且只测 **被 jbb 拦截的路径**（无 syscall）才是 jbb 自身成本。

### 6.4 正常结果长什么样

```
csops flags=0x22007001  GET_TASK_ALLOW=0 DEBUGGED=0
dyld count=N susp=0 dup=0 unique=N
stat /var/jb ... 全部 ENOENT
env DYLD_INSERT=(null)
```

## 8. 关键设计决策与教训

1. **形态选 tweak，不选 basebin。** 试过把 jbb 编进 roothide 的 `basebin`（systemhook 末尾 dlopen）：因为要隐藏 TweakInject 必须用全量 `rebind`，结果把 dyld/shared cache 的符号指针也改了，**App 大面积秒退**。回滚方案见 §4。tweak + 91 App 名单已经够用。
2. **延迟安装 hook 不需要**：把 jbb 放在 systemhook 的 TweakLoader 之后加载即可避免 `/TweakInject` 豁免，但 tweak 形态本来就晚于 TweakLoader。
3. **入口 plist 必须是 binary + `isController=true` + icon**，否则 Settings 不显示（这是这次"设置里看不见 jbb"的真正原因）。
4. **Choicy 的门禁思路**被采纳为 `enabled` 主开关 + 环境变量 `JBB_DISABLE`；没采纳 hook `dlopen`（jbb 是被加载方）。
5. **Apelin 的工程规则**：签名最后一步、`-fvisibility=hidden`、`-ffile-prefix-map`、dSYM 先于 strip、用 os_log 做加载标记。

## 9. 怎么改

**加一个新 hook**：在 `src/jbb_v616.c` 里写 `h_xxx` + `o_xxx`，在 `jbb_init` 的对应分组里 `jb_hook("xxx", h_xxx, (void **)&o_xxx)`，并把开关接到 `gXxx` 与 profile key。

**加一个 token**：只加本机真实痕迹到 `kJBTokensCore`；其他生态的加到 `kJBTokensExtra`。改完重建，锚点索引会自动重建。

**加一个设置开关**：`prefs/JBBPrefs/JBBAppSettingsController.m` 的 `JBBKeys()` 加一行 `@[@"key", @"标题"]`；jbb 侧在 `jb_load_profile` 里读同名 key。

**改注入名单**：`packaging/com.pandan.jbb/usr/lib/TweakInject/jbb.plist`（91 项）。
